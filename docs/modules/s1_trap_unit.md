## Purpose

The M-mode trap entry and `mret` exit unit. It is separate from the CSR file so that a retiring
instruction can atomically request all trap-state writes and the fetch redirect in the same cycle,
while the CSR file remains the single owner of CSR storage.

## Interface contract

The retire stage supplies `trap_valid_i` or `mret_valid_i` as a one-cycle pulse and keeps the CSR
read data stable for that cycle. A caller may issue a trap only while the unit is in `S_NORMAL` and
an `mret` only while it is in `S_TRAP`; invalid transitions are deliberately ignored.

| Signal | Dir | Width | Meaning | Contract |
|---|---|---|---|---|
| `clk_i` | in | 1 | clock | single domain |
| `rst_ni` | in | 1 | reset | async assert, sync de-assert |
| `trap_valid_i` | in | 1 | trap request | one-cycle pulse at retire; accepted only in `S_NORMAL` |
| `trap_cause_i` | in | 6 | exception or interrupt code | zero-extended on the `mcause` write |
| `trap_tval_i` | in | `WIDTH` | faulting address or instruction bits | written to `mtval` on an accepted trap |
| `trap_pc_i` | in | `WIDTH` | faulting or next PC | written to `mepc` on an accepted trap |
| `mret_valid_i` | in | 1 | `mret` request | one-cycle pulse at retire; accepted only in `S_TRAP` |
| `mstatus_rdata_i` | in | `WIDTH` | current `mstatus` | sampled combinationally when forming the `mstatus` write |
| `mepc_rdata_i` | in | `WIDTH` | current `mepc` | redirect target for an accepted `mret` |
| `mtvec_rdata_i` | in | `WIDTH` | current `mtvec` | redirect target for an accepted trap |
| `hw_we_o[4]` | out | 1 each | hardware CSR write enables | slots 0–3 are `mepc`, `mcause`, `mtval`, `mstatus` |
| `hw_addr_o[4]` | out | 12 each | hardware CSR addresses | valid when the corresponding write enable is high |
| `hw_wdata_o[4]` | out | `WIDTH` each | hardware CSR write data | valid when the corresponding write enable is high |
| `redirect_valid_o` | out | 1 | PC redirect request | asserted for each accepted request |
| `redirect_pc_o` | out | `WIDTH` | PC redirect target | `mtvec_rdata_i` on trap, `mepc_rdata_i` on `mret` |

**Handshake:** none. Requests are one-cycle pulses; the CSR write port and redirect are valid in
the same cycle as an accepted request.

**Latency:** zero cycles for CSR-write and redirect outputs; the FSM state changes on the following
active clock edge.

**Backpressure:** none. The unit never stalls retirement. A request that is invalid for the current
state is a strict no-op.

**Reset state:** `state_q = S_NORMAL`. With both request inputs low, every write enable and
`redirect_valid_o` is low, and all address, data, and redirect-PC outputs are `'0`.

## Behaviour

The FSM has two states: `S_NORMAL` before trap entry and `S_TRAP` while executing the M-mode trap
handler. An accepted trap moves `S_NORMAL` to `S_TRAP`; an accepted `mret` moves `S_TRAP` back to
`S_NORMAL`.

On an accepted trap, the unit drives all four hardware CSR write slots atomically:

1. `mepc ← trap_pc_i`
2. `mcause ← zero_extend(trap_cause_i)`
3. `mtval ← trap_tval_i`
4. `mstatus.MPIE ← mstatus.MIE`, `mstatus.MIE ← 0`, and `mstatus.MPP ← M`

It simultaneously redirects fetch to `mtvec_rdata_i`.

On an accepted `mret`, the unit writes `mstatus.MIE ← mstatus.MPIE`, sets
`mstatus.MPIE ← 1` and `mstatus.MPP ← M`, then redirects fetch to `mepc_rdata_i`. The remaining
`mstatus` bits are preserved in both operations.

## Exceptions and errors

None. This unit consumes trap and `mret` requests generated by retirement; it does not create
exceptions. Requests presented in the wrong FSM state are ignored without an error response.

## Known limitations

- M-mode only. S-mode and U-mode transitions, delegation through `medeleg`/`mideleg`, and lower
  privilege returns are outside the v1.0 implementation scope.
- `mtvec` is used directly as the redirect target; vectored interrupt-mode address calculation is
  not implemented here.

## Open questions

None. When S-mode support is implemented, this unit will retain trap-delegation ownership so that
target-mode selection, CSR updates, and fetch redirect remain one atomic operation.
