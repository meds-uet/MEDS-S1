# `verif/` — Verification

## What lives here
Everything that decides whether the design is correct, in five layers (SPEC §28).

## What does *not* live here
RTL. Testbench-only helper modules go in `verif/common/`.

## How to add something
Find the layer your work belongs to and read that subdirectory's README first.

## Catalogue projects that land here
all verification projects
