# `sw/` — Software

## What lives here
Everything that runs on MEDS-S1 or drives it from the host.

## What does *not* live here
RTL, generator code.

## How to add something
Start in `sw/bsp/`. `sw/apps/hello` is the smallest complete example.

## Catalogue projects that land here
all software projects
