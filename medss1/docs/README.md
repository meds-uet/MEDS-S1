# `docs/` — Documentation

## What lives here
Design guidelines, module documentation, architecture decision records, review records, and the generated specification PDF and figures.

## What does *not* live here
The normative specs — those are in `specs/`.

## How to add something
Docs are reviewed like code. The wiki is deliberately disabled: it is unversioned and it rots.

## Catalogue projects that land here
M-10 CI docs gates · M-13 module documentation sweep
