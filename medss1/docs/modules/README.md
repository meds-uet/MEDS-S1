# `docs/modules/` — Module documentation

## What lives here
One page per RTL module: interface contract, parameters, latency, exceptions, verification status. `TEMPLATE.md` is the required shape.

## What does *not* live here
Tutorials.

## How to add something
NFR-7: every module has one before its PR merges. CI checks presence, reviewers check content.
