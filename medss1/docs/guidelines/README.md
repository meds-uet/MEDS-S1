# `docs/guidelines/` — Design guidelines

## What lives here
The coding standard, verification guide, review checklist, git guide and onboarding path.

## What does *not* live here
Design decisions with a rationale — those are ADRs in `docs/adr/`.

## How to add something
These are enforced by `scripts/check_structure.py` wherever they can be. A rule nobody can check is advice, not a standard.
